## Exact intentional exclusions

Global technical exclusions apply to all pages: route/request identifiers; imported component/icon names; CSS and animation literals; raw image/map/file sources; existing accessibility/control identities; fixed item IDs; list/table numbering; date formatting; generated record counts and enrolment totals. They remain fixed so content edits cannot restructure the application. Existing database-owned fields are category B, not SiteContent.

| Page | Excluded source fields / copy | Reason |
| --- | --- | --- |
| SchoolInfo | schoolData.nocDate, affiliationSince, trustAddress, areaSqm, grievanceEmail, grievancePhone, sexualHarassmentContact, sexualHarassmentEmail; child-only Date/Since/Valid up to/Phone/Contact captions | InfoCard ignores children, so these are not displayed in the original. Revealing them would add public content/layout. |
| Contact Us | Message Sent!; Thank you! We'll get back to you shortly.; Sending...; original map accessibility title and URL | Fixed operational feedback / technical map semantics; no change to simulated submit behavior. |
| Login | Email, Password, their placeholders, Sign In, Signing in, fixed auth errors, form identity/type/required flags and routes | Auth/validation/control identities must not become editable. |
| NotFound | 404 | Fixed status-code presentation; routing/status behavior remains unchanged. |
| Downloads | General grouping fallback, file icon extension cases and direct file destinations | Preserve grouping/record/file-serving logic; actual record categories/files stay in original CRUD. |
| All structured lists | Original category/status/color metadata, IDs and generated ordinals | Displayed category/status captions have independent fields; metadata is not editable. |
| Mandatory Public Disclosure | Entire source and document content | Category D, reserved for Prompt 03. |
